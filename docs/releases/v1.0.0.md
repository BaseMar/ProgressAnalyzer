# Workout Progress Analyzer v1.0.0

Released 10 November 2026.

A single-user training application that connects versioned plans, recorded
workouts and explained recommendations for the next session.

## Included

- Four task-oriented pages: Overview, Analysis, Plan and History.
- Dated plan revisions, stable exercise history and confirmed replacements.
- History-based starting loads and per-set progression with source explanations.
- Explicit external, bodyweight and assisted loads, timed exercises and missing RIR.
- Manual entry, workout-note import and calendar-based corrections.
- Exercise comparisons, plan completion, muscle allocation and body measurements.
- A public sandbox with fictional data and independent browser-session edits.
- A persistent personal app with SQLite or PostgreSQL, additive migrations,
  portable native backups and restore into a separate empty target.
- Docker Compose with PostgreSQL persistence and generated first-start data.
- English documentation, interface text, comments and docstrings.

## Start

```sh
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

For your own database, use `streamlit run personal_app.py` after following
[local setup](../getting-started.md). Existing installations retain their records;
the public entry point now runs the temporary sandbox regardless of stored
personal connection settings. Docker keeps its persistent database behavior.

## Verification and limits

GitHub Actions checks Python 3.11 and 3.12, including PostgreSQL 16 integration,
native backup/recovery, session isolation, Streamlit reruns, linting, formatting
and compilation. A separate job builds the Docker image and verifies persistent
data after container recreation. Desktop and mobile screenshots use generated
data at 1440 px and 390 px.

The personal application has no accounts or multi-user isolation. The public
sandbox is temporary. Recommendations explain recorded evidence and application
rules; they do not assess exercise technique or recovery capacity. See the
[calculation rules](../calculation-rules.md) and
[recommendation policy](../progression-rules.md) for assumptions.
